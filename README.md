Garritas - Tienda de Productos para Mascotas

Proyecto Integrador desarrollado para la Tecnicatura. Sitio web e-commerce enfocado principalmente en la venta de juguetes y accesorios para perros.

Instrucciones de Uso
1. Acceso: Iniciar sesión para habilitar las funciones de compra. Si no dispone de una cuenta, acceder a la opción de registro desde el formulario.
2. Navegación y Selección: Explorar el catálogo y ajustar las cantidades deseadas antes de añadir al carrito.
3. Gestión de Carrito: Acceder al carrito para verificar los ítems, modificar cantidades o remover productos indeseados.
4. Finalizar Compra: Confirmar la orden para generar el resumen interactivo de la compra en la pantalla.
